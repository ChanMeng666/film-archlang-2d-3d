# Audio credits: film-archlang-2d-3d

Every file below is a real recording or a sound designer's library effect from a royalty-free or
CC0 source. No AI-generated music or voice. The media files are gitignored: `npm run audio`
downloads them again, checks each SHA-256 against `audio/manifest.json`, and stages them in
`public/audio/` for Remotion.

Eight files are the ones the owner approved for archlang-cinematic (same URLs, same hashes). Three
Kenney interface sounds are new here, CC0 from the same mirror and pack family; the owner approved
them on 2026-11-07.
