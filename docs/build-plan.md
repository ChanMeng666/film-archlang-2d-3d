# Build plan

Cards are done in order. Each card ends with a check that someone other than its author can run.
Read `docs/creative-brief.md` and `docs/storyboard.md` first.

## Stack

- **Remotion** (pin an exact 4.0.x that is at least two weeks old, the same for every `@remotion/*`
  package) for composition, captions and encoding. 1920×1080, 30 fps, H.264 + AAC.
- **Core and 3D from npm**, exact pins: `@chanmeng666/archlang@1.57.0`,
  `@chanmeng666/archlang-3d@0.4.0`. No vendored tarballs and no link to the local archlang checkout,
  so the film shows what a user installs.
- **Playwright** (`playwright-core` + one Chromium) for playground screen captures and for
  `archlang3d view --video`. One browser at a time.
- **ffmpeg** (on PATH) for loudness measurement, the mux and the SRT burn check.
- Node 24 is installed. Use `npm`, not pnpm or yarn.

## Layout

```
source/            .arch files the film shows (copies of core examples + broken-flat variants)
scripts/bake.mjs   compile / describe / lint / finish / export / 3D build, writes public/baked + data/facts.json
scripts/capture.mjs  Playwright captures of playground.archlang.uk and archlang3d replays → public/captures
scripts/gate-copy.mjs  banned-word and unfilled-slot gate over src/copy.ts, SRTs, docs/post-copy.md
scripts/gate-facts.mjs every {slot} resolves, each scene's assertions hold (see storyboard "Source" lines)
scripts/srt.mjs    writes out/*.srt from src/copy.ts and the scene timings
audio/             fetch script, manifest with SHA-256, CREDITS.md (media gitignored)
src/               Remotion: Root.tsx, scenes/S0…S11, copy.ts, theme.ts, timings.ts
public/            baked SVG/PNG/MP4/GLB (gitignored; regenerated by bake + capture)
data/facts.json    numbers the captions use (committed, regenerated by bake, never hand-edited)
out/               renders (gitignored)
```

## Cards

### F1 Scaffold
Remotion project with one composition, `MasterEN` (the film is English only, owner 2026-11-07).
Scripts: `bake`, `capture`, `audio`, `gates`, `studio`, `preview` (half scale), `render:en`, `srt`.
Copy `brand/archlang-logo-master.svg` from the archlang repo byte for byte, and check its SHA-256
matches the archlang repo's in `gates`. Fonts: Inter and JetBrains Mono from `@fontsource/*` (no
network fetch at render time).
**Check:** `npx remotion compositions` lists it; `npm run gates` runs (it may fail on empty data).

### F2 Bake
`scripts/bake.mjs` reads the pinned packages and writes every artefact the storyboard names: SVGs
for S0–S6 and S10, the `LIVING` sweep for S4, `lint --json` before and after for S1/S5, `finish`
output for S6, theme variants, export files for S8, GLBs for S7/S10, and `data/facts.json` with
every slot. It writes `source/broken-flat.arch` and its fixed form from the knob flat with explicit
edits (documented in the file's header comment). Use the library API where it exists, and the CLI
through `node node_modules/@chanmeng666/archlang/dist/cli.js` otherwise.
**Check:** a second `npm run bake` produces byte-identical `data/facts.json` and SVGs (hash
listing in `data/bake-manifest.json`); the scene assertions in the storyboard pass in
`gate-facts`.

### F3 Captures
`scripts/capture.mjs`: Playwright at a fixed 1920×1080 viewport, device scale 1, reduced motion
off. Capture the playground moments (S2 edit view, S3 room facts, S4 knob drag, S5 Checks,
S7 Plan | 3D switch) as video, with links built by `archlang link` from the baked sources, so
the playground shows exactly our file. Capture `archlang3d view --replay --video` for
`knob-flat`, `furnished-flat` and `two-storey`, plus one orbit, and the 3D stills for the gallery.
If a playground interaction cannot be driven reliably, fall back to a Remotion replica that draws
the baked SVG, and record which scene fell back in `docs/production-log.md`.
**Check:** every capture file exists, plays in ffprobe, and has the planned length ±0.5 s.

### F4 Scenes
Build S0–S11 per the storyboard, all captions from `src/copy.ts`. Timings in `src/timings.ts`.
Motion: ease in-out cubic, no bounce, caption fade 8 frames. Keep plum as the only accent colour.
**Check:** `npm run preview` renders a half-scale master (about 140 s planned; 196 s once the voice set the pace) with no missing assets;
frame stills at the middle of every scene go to `out/review/` for the owner.

### F5 Audio
Music bed and SFX from Mixkit / Kenney (real recordings), fetched by `audio/fetch.mjs` with SHA-256
in `audio/manifest.json` and credits in `audio/CREDITS.md`. The archlang-cinematic project's
`audio/manifest.json` lists tracks the owner already approved. Prefer those, and read their
licence rows before reuse. Mix in Remotion (`<Audio>` with volume curves), then measure the
rendered file with `ffmpeg -af ebur128`. Target −14 LUFS integrated, −1 dBTP true peak.
**Check:** the measured numbers go into `docs/production-log.md`. State there that the mix has not
been heard by a person until the owner has listened.

### F6 Subtitles, gates
`scripts/srt.mjs` writes `out/archlang-2d-3d-en.srt` from `copy.ts` and `timings.ts`.
`gate-copy` and `gate-facts` both pass.
**Check:** `npm run gates` green; the SRT parses with ffmpeg (`ffmpeg -i x.srt -f null -`).

### F7 Final render (owner go-ahead only)
Full 1080p `render:en`, `--concurrency=1`. Poster and thumbnail from
the S7 half-risen frame.

**Done 2026-11-07:** master approved by the owner; poster and thumbnail from the `Poster`
composition (`npm run poster`), the knob-flat replay at 5.4 s.

### F8 Cuts (after the owner approves the master)
30 s 16:9 and 9:16, laid out again for vertical (the scenes take an `aspect` prop), never cropped.

**Done 2026-11-07:** `render:cut30`, `render:cut30v`; 31.5 s each (see the production log).

## Rules for executors

- One heavy process at a time: one bake, one browser, one render. Half-scale previews only until F7.
- Never type a number that a caption shows. Put it in `data/facts.json` through the bake.
- Never invent geometry, UI or agent output. A capture is of the real thing, or it is a replica
  that draws baked compiler output, and the production log says which.
- No secrets. Nothing needs a key. The repo stays local until the owner asks to publish it.
